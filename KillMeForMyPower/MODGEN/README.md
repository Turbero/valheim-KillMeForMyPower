# Kill Me For My Power

Showcase link: https://www.youtube.com/watch?v=Mg5w6QN9Fzk

![](https://i.imgur.com/AfvqcVx.jpeg)

The Kill Me For My Power mod contains several features to block new players that want to take shortcuts in servers or local games.

# What can you do with this mod

## Block powers

Block obtaining the forsaken powers without killing them first. Useful in servers to force new players to have the full biome experience!
* Scare the cheeky players that attempt to obtain the powers of enemies not killed yet by them with little damage effects.
* Custom the messages in your own language

## Setup boss battle conditions

* Choose if the boss win is awarded to all players nearby (default) or only the one that hits last.
* Decide how many players must be around the altar to spawn a boss (default = 1)
* Choose a range around an altar where the player cannot place any pìece on the ground (default = 0 meters)

## Lock vendors

Lock vendors even if you find them too soon until you kill the corresponding forsakens! Choose the boss to unlock them. By default:
* Haldor: need to defeat Eikthyr before buying anything
* Hildir: need to defeat Eikthyr before buying anything
* Bog Witch: need to defeat The Elder before buying anything

Remove these restrictions, leave them or add more to your choice. When it is not possible to buy anything to a vendor a yellow message will pop up on screen, meaning it is still locked.

![](https://i.imgur.com/Weo2srk.png)

Change the necessary boss to your choice before showing up in the vending list. Also select individual items to lock. By default:
* Thunderstone: need to defeat The Elder
* Ymir meat: need to defeat The Elder
* Chicken egg: need to defeat Yagluth

## Dungeon restrictions

* Avoid players going into further biome dungeons before killing the previous biome boss
* Additionally, you can enable a block to avoid running away from Seeker Queen and final deep north boss battlefields if they're still alive

## Item restrictions

* Important items obtained with materials from bosses are locked to use until you don't defeat them:
  * Antler Pickaxe cannot be equipped until you defeat Eikthyr
  * Crypt Key cannot be used until you defeat The Elder
  * Wishbone cannot be equipped until you defeat Bonemass
  * Wisplight cannot be equipped until you defeat Yagluth

## Bosses Loot drops

Decide how many drops the bosses will drop to the fighters:
* Default → same as vanilla (one key/wishbone per player connected, a s***)
* One Player → a set of drops equivalent to a one player fight, even if several participated in the battle
* Drops For Each Player Nearby → a set of drops for each player nearby the boss when dying (1 trophy and n-items for each one)

## EpicMMO integration

If EpicMMO mod is enabled:
* avoid people spawning bosses that they cannot kill yet.

![](https://i.imgur.com/8XOJhQK.jpeg)

## Days of restriction

If a world lasts for a lot of game days, you can set up a limit of days per boss from which the players can learn boss powers without killing them.

For example:
* if you set up 100 days for Eikthyr, players will be able to learn Eikthyr power without killing him only from day 100 of the world.
* if you set up 250 days for The Elder, players will be able to learn The Elder power without killing him only from day 250 of the world.
* and so on. It's configurable for each existing boss

(By default, day limit is day 100000 for all bosses)

## Limit skill leveling

Restrict leveling up more than the indicated level in the configuration before killing each boss. Examples:
* set up that before killing Eikthyr you can only level up skills until 20
* set up that before killing The Elder you can only level up skills until 35
* and so on. It's configurable for each existing boss

## Power Granted player lists

Here the names of the players who have defeated each boss are saved (server-side). This can be updated manually by admins in case of any trouble.

(Monstrum Deep North mod bosses are also included!)
